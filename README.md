# AutoChord 自動撥弦鍵盤

以鋼琴鍵盤介面觸發吉他分解和弦的小工具。點白鍵（Do~Ti / 1~7）或黑鍵即可依所選指法自動循環撥弦。

## 功能
- 指法可選：T1213121、T123 121、T132T132、(32T)1(32)1(32)1(32)1… 或自訂
- 白鍵 = 該調順階和弦，黑鍵 = 升降根音和弦；Shift / 右鍵 = 小和弦
- 音色：鋼琴、尼龍吉他、木吉他（取樣，需網路），以及離線合成音色
- 調性、速度、和弦類型、畫面縮放（預設 50%）
- 桌面版（Electron）視窗永遠置頂

## 使用
- 瀏覽器：直接開啟 `index.html`
- 桌面版：安裝 Node.js 後執行 `start.bat`（第一次會自動 `npm install`）

## 快捷鍵
1–7 白鍵、Q W E R T 黑鍵、空白鍵/Esc 停止、Ctrl +/- 縮放
